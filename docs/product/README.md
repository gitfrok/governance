# Product

Product-level requirements: who the product is for, what it must do, what it will never do, and how
success is measured. Sits **above** `../roadmap/` → `../backlog/` → `../tasks/` and is cited by
`../specs/`.

**Not** a source of truth for architecture — `../adr/` is (ADR-0001). Where this directory appears
to decide architecture it is restating an Accepted ADR; anything requiring a new decision is listed
as needing a Proposed ADR.
